# 漢字の塔：テスト範囲の足しかた

テスト範囲は、文章を書いたファイル1つから作ります。必要なものは、このリポジトリの中に全部あります。

## 新しい範囲を足す

1. `tower/ranges/` に、範囲ごとのファイルを作る（例：`3g-01-02.txt`）。ファイル名の順が古い順で、最後のファイルが「いちばん新しい範囲」として最初に開きます。

   ```
   id: 3g-01-02
   title: 3学期 1・2回目
   grade: 3

   ## 1回目
   ビルの{二|に}{階|かい}に{住む|すむ}。
   {部屋|へや}をそうじする。
   ```

   - `id`：半角の名前。保存データの見出しになるので、あとから変えない。
   - `title`：画面に出る名前。
   - `grade`：学年。これより下の学年で習う字は「知っているはず」として、確かめから始まります。
   - 1行が1つの文。`{こたえ|よみ}` が1問です。こたえには送りがなも書きます（`{住む|すむ}`）。
   - 二字で一つの読み（熟字訓）は、まとめて1問にします（`{部屋|へや}`）。
   - `#` で始まる行はメモです。

2. データを作る。

   ```
   node tower/tools/build_range.cjs tower/ranges/3g-01-02.txt
   ```

   `tower/data/3g-01-02.js`（出題データ）と `tower/data/ranges.js`（範囲の一覧）ができます。画面側の変更は要りません。

3. 確かめる。

   ```
   node tests/tower-core.test.cjs
   ```

## 範囲を直す

範囲ファイルを書き直して、同じコマンドをもう一度実行します。字が同じなら、子どもの記録（★や次に出る日）はそのまま残ります。

## 手で足せる表（なくても動く）

`build_range.cjs` の先頭にある表です。新しい字が増えたとき、必要に応じて足します。

| 表 | 役割 | ないとき |
|---|---|---|
| `CONFUSE` | 「どの字？」で混ぜる、形・読み・意味がにている字 | 同じ部品を持つ字から自動で選ぶ（読み・意味がにている字は選べない） |
| `MEMO` | 字の覚え方の一言 | 部品の名前から作る |
| `RAD` | 部品（部首）の呼び名 | 字そのもの、または「左の 部品」のように場所で呼ぶ |
| `ALIKE` | 形がにている部品 | 同じ場所・近い画数の部品から選ぶ |

実行すると、まぎらわしい字を自動で選んだ字が表示されます。気になるものだけ `CONFUSE` に足して作り直してください。

## 使える字

小学校で習う漢字（1〜6年）と、ひらがな・カタカナです。字形と部品の区切りは `kanji-db.json` に入っています。

## kanji-db.json を作り直すとき（ふだんは不要）

```
node tower/tools/build_db.cjs <KanjiVG の kanji フォルダ> <学年別の漢字リストのフォルダ> > tower/tools/kanji-db.json
```

- KanjiVG は、部品の区切り（`<g kvg:element=…>`）が残っている元の SVG が必要です。いまのデータは npm の `kanjivg-js` に入っている `kanji/` から作りました。
- 学年別リストは `grade.g01.json`〜`grade.g06.json`（漢字の配列）。いまのデータは npm の `kanji` に入っている `lib/data/` を使いました（各学年 80・160・200・200・185・181字）。
